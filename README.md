# Rachel · AI业务项目展示

本仓库用于统一管理Rachel的AI业务项目、交互式HTML Demo、HTML PPT及AI月度汇报等网页应用。

## 目录说明

| 位置 | 内容 | 类型 |
| --- | --- | --- |
| `index.html` | AI项目展示首页，提供各业务项目和月度汇报入口 | 网站首页 |
| `voc-tag/index.html` | VOC标签体系介绍 | HTML介绍页面 |
| `voc-tag/VOC标签应用Demo.html` | VOC标签应用Demo，产品功能与质量问题分析 | 交互式HTML |
| `geo-tag/index.html` | Listing&GEO优化Agent | 交互式HTML PPT |
| `ai-monthly/index.html` | AI月度汇报导航首页，按月份查看汇报 | HTML导航页面 |
| `ai-monthly/2026-09/index.html` | 2026年9月《OEC-AI产品进度说明和规划》 | 交互式HTML PPT |
| `ai-monthly/README.md` | 月度汇报项目的中文说明和访问地址 | 项目说明 |
| `AGENTS.md` | Codex项目开发、维护及交付规范 | 开发规范 |

各项目可以独立更新，`index.html`为GitHub Pages目录默认入口。两个VOC页面位于同一层级；月度汇报统一归档在`ai-monthly`，每个月份独立维护。

## 访问方式

从GitHub Pages网站首页进入对应项目；网站目录中的链接采用相对路径，仓库更名后无需手动更改首页地址。

- AI项目导航：https://rachelsxcat.github.io/rachel-tags/
- AI月度汇报：https://rachelsxcat.github.io/rachel-tags/ai-monthly/
- 2026年9月汇报：https://rachelsxcat.github.io/rachel-tags/ai-monthly/2026-09/

**注意：**GitHub Pages公开页面不适合放置需要保密的内部数据。
