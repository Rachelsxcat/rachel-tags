# AI月度汇报

本目录集中管理Rachel的AI月度汇报，按年份和月份归档交互式HTML PPT，避免每个月都在仓库根目录创建独立项目。

## 页面与文件

| 文件位置 | 内容 |
| --- | --- |
| `index.html` | AI月度汇报导航，按月份访问各期汇报 |
| `2026-09/index.html` | 2026年9月《OEC-AI产品进度说明和规划》交互式HTML汇报 |

## 网页访问地址

- 月度汇报导航：https://rachelsxcat.github.io/rachel-tags/ai-monthly/
- 2026年9月汇报：https://rachelsxcat.github.io/rachel-tags/ai-monthly/2026-09/

## 更新规则

- 新增月份时，创建`YYYY-MM/index.html`并在本目录`index.html`新增相应月份入口，同时维护本README。
- 已有月份修改时，默认更新该月份原有`index.html`，保留原访问地址，不创建重复版本文件。
- 月度导航保留现有视觉风格；各月正式汇报以对应源文件为准，未经要求不改动业务内容或交互。
